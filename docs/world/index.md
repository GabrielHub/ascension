# World Foundation Reference

This folder is the tone, voice, and lore anchor for *Hazard-Pay: Dungeon Management*. Consult it when **writing** anything player-facing — copy, narrative, event briefings, asset captions, story beats, character voice.

This folder is **not** for content lists, room catalogs, weapon tables, dungeon rosters, or any enumerated content — those live in `docs/product/`. Code is the source of truth for implemented gameplay behavior.
