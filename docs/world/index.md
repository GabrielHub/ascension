# World Foundation Reference

This folder is the canonical thematic and content-design anchor for all authored content. Consult it before generating any content in any domain: visual design, environmental art, operator and character art, copy and naming, narrative writing, event authoring, SFX direction, room and building flavor, gear and item descriptions, dungeon concepts, and any other authored material that a player or content creator will see, hear, or read.

Code remains the source of truth for implemented gameplay behavior. The product plan owns future gameplay and system decisions. This folder owns future-facing narrative rules, thematic consistency, and content-reference guidance across every content domain.
