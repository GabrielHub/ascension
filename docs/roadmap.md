# Hazard-Pay Roadmap

Deferred ideas for after the initial rewrite scope. Do not author implementation plans for these until a future decision moves them into active scope.

## Deferred Features

- Direct rival battles.
- Rival HQ visibility and rival rosters.
- Tauri desktop host and file-backed saves after the web game is feature-complete.
- Rooftop helicopter pad and international expansion floor.
- Mobile or responsive UI.
- Keyboard shortcuts.
- Music expansion beyond the existing carried-forward tracks.
- AI-generated rival event framing.
- AI-generated weapon flavor framing.
- Regular enemy visual assets.

## Roadmap Rules

- Keep actionable work out of this file. Actionable work belongs in `docs/plans/rewrite/`.
- When a deferred feature becomes active, write or update the relevant product doc first, then create a numbered implementation plan.
- Remove an item from this roadmap only when it has an active product contract and implementation plan.
