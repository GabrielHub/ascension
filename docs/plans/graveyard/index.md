# Plan Graveyard

Completed Hazard-Pay rewrite plans move here after review. This folder exists so future agents do not keep rereading completed implementation plans as active context.

Rules:

- Move a plan here only after its status is `completed`.
- Remove the plan from `docs/plans/rewrite/index.md` when it moves here.
- Keep the completed plan file intact so future archaeology can inspect what shipped.
- Do not store old Ascension execution plans here. They are not new-game canon.
